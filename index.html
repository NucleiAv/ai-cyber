Before you attack anything

Only test systems that you own or that give you written permission. The labs and CTFs on this site exist for this purpose. Bug bounty programs list what is in scope. Stay inside it.

Use a local model on Ollama as your first target. Run payload files, such as the pickle lab, in a throwaway virtual machine. If you find a leaked key, report it. Do not use it.
