AI for cyber security

How defenders use AI for detection, threat intelligence and code review, and how to defend AI systems. Each module starts with a plain primer, then opens the course sections, labs and practice desks inside this site.

How each module works

  1. The idea in one minute and learn it from zero. A plain primer, step by step, with diagrams.
  2. Read the sections. Each NYU section opens inside this site with its own diagrams, knowledge checks and labs. A short plain-words summary sits on top.
  3. Practice desk. Modules 3, 4, 5, 6, 8, 9 and 11 turn the class workbook into interactive questions with instant feedback. The answers come from the class answer slides.
  4. Interactive labs, framework maps, the lecture slides inline, a quiz and references.

Module 7 was not in the course export, so it is not here.
