Agents, the future of AI security, and your career

From a prompt to a loop. How security agents work and fail, how to read claims about the future without the hype, and how to map your own skills to real jobs.

The idea in one minute

Every model in this course so far had a human between its output and the world. An agent removes that human for some steps. It plans, calls tools and acts in a loop. So an agent deployment is really an authorization decision. What may it do alone, and what needs a person?

The module ends with your career. Employers want AI security skills you can show, not only name.

Think of it like this

A chatbot is a friend who gives advice. An agent is a friend you gave your car keys and your bank card. Before you hand them over, you decide exactly what errands they may run.

Learn it from zero

Step 1. From prompt to loop

The ReAct pattern has the model write a thought, pick an action, read the observation, and repeat. A tool call is only structured text that the app turns into a real action. The first exploit of a loop is simple. Tool output is untrusted text, and the model reads it as context.

Step 2. Workflow or agent?

A workflow follows fixed steps in code, with a model inside some steps. An agent chooses its own steps. Use an agent only when the path cannot be fixed in advance. A workflow is easier to test and audit.

Step 3. Four parts of an agent, and how they fail

An agent has a model, tools, memory and a control loop. Each can fail. The model misjudges, a tool has too much power, memory gets poisoned, and the loop runs too long or acts too fast. A few seconds is enough for an agent with delete rights to cause lasting damage.

Step 4. Constraints that survive an audit

Least privilege per tool, approval gates before irreversible steps, budgets on steps, tokens and time, scope rules, and full logs of every tool call. Open source autonomous pentest tools such as ARTEX build these same brakes in, with scope gates, command rules, approval gates and budgets. The attack track's lesson 9 covers it as a case study.

Step 5. Read the future without the hype

Sort each claim into one of three bins. Demonstrated with public evidence, plausible but not shown, or speculation. Check who benefits from the claim. Weigh vendor reports against independent studies.

Step 6. Map your skills

Build an evidence matrix. For each skill a job posting asks for, write what you did, where the proof is, and how a reviewer can check it. Labs, CTF writeups, detection rules and policies from this course count as evidence.

Words you need

Agent
A model in a loop that picks tools and acts until a goal is met.
ReAct
Reason and act. Thought, action, observation, repeat.
Workflow
Fixed steps in code, with models inside some steps.
Approval gate
A human decision required before an action runs.
Three-bin method
Sort a claim as demonstrated, plausible or speculation.
Evidence matrix
A table that links each skill to proof a reviewer can check.
