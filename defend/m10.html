Adversarial AI. Poisoning, evasion and the ML supply chain

The classic attacks on machine learning. Poison the training data, craft inputs the model gets wrong, hide code in a model file, and see harm from an agent with no attacker at all.

The idea in one minute

Before LLMs, researchers studied attacks on every kind of ML model. Those attacks still apply, to malware classifiers, phishing detectors and LLMs alike.

  • Poisoning attacks the model while it learns.
  • Evasion attacks the model while it predicts.
  • Supply chain attacks the files and tools around it.
  • Excessive agency shows harm with no attacker, when an autonomous system acts beyond its limits.
Think of it like this

Poisoning is teaching a student wrong lessons. Evasion is a trick question built to fool a student who learned the right lessons. A supply chain attack is swapping the student's textbook.

Learn it from zero

Step 1. Data poisoning

Three ways to poison a training set.

  • Label flipping. Change labels, such as marking malware as benign.
  • Backdoor. Add a trigger pattern with a target label. The model learns "trigger means benign".
  • Clean-label poisoning. Add samples with correct labels but crafted features, so a human reviewer sees nothing wrong.

At web scale, attackers only need a small number of poisoned items in a huge crawl. Lesson 7 of the attack track shows that about 250 documents were enough for LLMs of many sizes.

Step 2. Evasion and adversarial examples

An adversarial example is an input with a small, crafted change that flips the model's answer. For many models it is found by optimization. One classic method, FGSM, moves each input value a small step in the direction that increases the model's error.

The attacker often does not need the model. Adversarial examples transfer between models trained on similar data, and query-based attacks probe the model through its API. For malware classifiers that read raw bytes, attackers append or change bytes in places that do not change what the program does.

Step 3. The ML supply chain

A model file can run code. Python pickle calls functions while it loads. Model hubs, datasets, notebooks and libraries are all trust points. A benchmarked model can also quietly lie, for example with a hidden backdoor or a changed fact.

Step 4. Harm with no attacker

An autonomous system can cause damage by itself if it can take irreversible actions with no check. The answer is the same as for attacks. Constrain agency. Put approval gates before irreversible steps.

Step 5. Three lenses

Classify every attack in three ways. Where in the lifecycle it acts, what the attacker needs to know or access, and what it breaks (integrity, availability or privacy). Frameworks such as MITRE ATLAS and NIST AI 100-2 give names for each.

Words you need

Adversarial example
An input with a small, crafted change that makes a model give a wrong answer.
Decision boundary
The line in feature space where the model's answer changes.
FGSM
Fast gradient sign method. A one-step way to make adversarial examples using the model's gradient.
Transferability
An adversarial example made for one model often fools another.
White box and black box
The attacker knows the model's insides, or only sees its outputs.
Clean-label poisoning
Poison samples with correct labels that still change what the model learns.
Approval gate
A required human decision before an action runs.
