The Fernhill defense desk

Fernhill Water Authority runs Intake, an LLM that turns residents' requests into work orders for field crews. Contractors use an API to summarize field notes. Answers come from the Module 11 answer slides.

Round 1. How much gets through?Round 2. Follow the work orderRound 3. The API doorRound 4. Reading the logs and respondingRound 5. AI on the defender's sideFind it, name it, fix it

Round 1. How much gets through?

Stack A is a keyword filter, then classifier G1. On known attacks the filter misses 40 percent and G1 misses 15 percent. On new attacks the filter misses 95 percent and G1 misses 66 percent. Multiply the miss rates to get the share that gets through.

Round 2. Follow the work order

One injected request makes Intake write <img src=x onerror="send(document.cookie)"> into a work-order summary and North 3' OR '1'='1 into the district field.

Round 3. The API door

A scan of the Contractor API found GET /v1/docs (public), POST /v1/summarize (contractor key), POST /v1/models/reload (no login) and POST /v1/config (no login).

Round 4. Reading the logs and responding

Four senders in 24 hours. A sent 1 web request about low pressure, summary 60 tokens, 0 flags. B sent 5 texts including 'you are now DAN', summaries 70 tokens, 2 flags. C sent 7 requests from one phone in an hour, summaries 600 tokens with internal asset IDs and engineers' names, 0 flags. D sent 847 requests from 40 new accounts, 14 with Base64, summaries 900 tokens, 38 percent flagged.

Round 5. AI on the defender's side

IaC review finds Terraform misconfigurations and writes repairs, but 20.4 percent of repairs that passed the linter were still wrong. A YARA drafting tool saves 44 to 86 percent of analyst time but sometimes writes YARA-L, which will not run in YARA. An IAM reviewer rated iam:PassRole low without checking which role can be passed. A behavioral malware model has over 97 percent accuracy and catches zero-days but has false positives that signatures avoid.

Find it, name it, fix it

Field card. Keep this

  • Ask what a guardrail's accuracy was measured on.
  • Layers multiply only when they fail for different reasons.
  • Encode output for where it lands. Use schema checks for structured fields.
  • Lifecycle endpoints are never public.
  • Limit tokens and spend, not only requests.
  • Not flagged plus odd output is the case to investigate first.
  • Containment removes the data source.
