Prediction 5. The limit

More practice. Name the technique

Field card. Keep this

  • A prompt is text, and roles are markers, not locks.
  • One run is a sample. Test on many runs and a labeled set.
  • Change one thing at a time, and record it.
  • Let the model judge. Let code copy facts.
  • Valid output is not correct output.
  • Prompt rules do not stop injection that arrives in the data.
