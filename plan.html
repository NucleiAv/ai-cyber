Rules of the plan

  • Each week has four parts. Learn, Practice, Extend and Reflect. If a week is busy, do only Learn and Practice.
  • Progress is the number of tasks done. Each Learn, Practice, Extend and Reflect task counts once, and so does each extra practice item and each end-of-module challenge.
  • Stuck for 30 minutes? Take a hint and write down what you missed.
  • For Reflect, write your own 5 lines first in the lesson page. Then open its model answer and compare.
  • Write one short public writeup for each end-of-module challenge. Do those challenges with a CTF teammate when you can.
  • New CTFs appear often. Check Awesome Prompt Injection once a month.
