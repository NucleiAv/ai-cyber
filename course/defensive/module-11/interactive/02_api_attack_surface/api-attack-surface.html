Endpoint Topology of an LLM Deployment

LLM frameworks expose far more endpoints than developers expect. Default configurations prioritize setup speed over security. An attacker with network access discovers, probes, and exploits endpoints that were never intended to be public.

A typical LLM deployment framework exposes endpoints for inference, model management, configuration, health checks, and data pipelines. Developers configure the inference endpoint and assume the rest is locked down. An attacker scans all of them.
