Real capability, real boundary

Google's Big Sleep found a genuine zero-day in SQLite that survived years of fuzzing. The agent's pattern-matching over source code surfaced a semantic edge case that random input mutation could not efficiently reach.

But the agent operated inside a purpose-built harness on a single codebase. It is not a general vulnerability scanner. Both attackers and defenders have access to the same technique.
