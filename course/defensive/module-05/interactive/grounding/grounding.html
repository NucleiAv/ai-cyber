Grounding: Memory vs. Source

Same prompt“Write a SOC briefing on CVE-2023-4863.”
Supplied source (given to the grounded run only)
“CVE-2023-4863: heap buffer overflow in libwebp, triggered by a crafted WebP image. Fixed in the build listed below; earlier builds affected.”

Ungrounded

drawn from training memory

Grounded

constrained to the source above

NOT IN SOURCE means the supplied source does not cover that claim. The same three blanks (a related CVE, exploitation status, the mitigation) appear in both runs. The grounded run flags them for you to verify, in KEV, the vendor advisory, and so on, instead of inventing an answer the way the ungrounded run does.

Grounding did not make the model smart; it made the task small. Open recall is pattern completion with no lookup step. Pasting the source converts it into constrained summarization, the task type language models actually do well.
