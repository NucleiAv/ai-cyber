Both developers made mistakes. Only one knew it.
The manual developer's lower confidence triggered a code review that caught the cookie issue before it shipped. The AI-assisted developer's inflated confidence meant three vulnerabilities reached production unchecked. The danger is not that AI writes bad code. The danger is that it suppresses the doubt that catches bad code. (Perry et al., 2023)
