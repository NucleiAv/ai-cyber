Classification is the first defensive move. Naming an attack "LLM01" vs "LLM07" vs "LLM06" tells you who owns the fix (app developer, model provider, or access design) and which layer to harden. Many real incidents chain several categories, a prompt injection (LLM01) that succeeds because of excessive agency (LLM06) and leaks data (LLM02). The primary tag names the entry point; the secondary tags name the blast radius.
