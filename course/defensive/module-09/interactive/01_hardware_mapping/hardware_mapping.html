The missing boundary, mechanism by mechanism

A classical computer resists code injection because of a stack of hardware mechanisms. A transformer has no equivalent for any of them. Open each row to line the protection up against its missing counterpart in the model.

Enforced in hardware Absent in the model
0 of 5 mappings explored
The pattern: every classical defense enforces the code-versus-data boundary below the level any input can reach, in hardware. A transformer offers no layer beneath the tokens, so there is nothing to enforce. This is why prompt injection is not a bug to be patched but a property of the architecture, and why defense can only wrap constraints around the model, never restore the boundary inside it.
