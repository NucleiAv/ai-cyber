Why the result changes: whether an injection lands depends on the model and the moment. Newer models are trained to refuse the injections that got publicized, so a well-known attack can simply bounce off; older and smaller models often still fall for it. Because that defense is training, not an architectural fix, the same hole reopens with the next attack. If a model resists every preset, edit the message and invent your own, or pick a weaker model from the list. This is a live language model, so results vary run to run.
